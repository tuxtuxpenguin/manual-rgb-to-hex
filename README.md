# rgb-to-hex converter

A python RGB to Hex converter built manually without using Python's built in `hex()` function.

I built this before finding out there was a built in hex function in python

This is extremely scuffed and may have issues

## Usage

1. have python installed
2. download or clone this repository
3. open rgb_to_hex.py in a preferred code editor
4. choose the RGB values at the bottom `rgb_to_hex(r=119, g=119, b=199)`
5. Run the file

It should convert the RGB values that you inputted into hexadecimal colour code

## Features

- Converting RGB to Hex
- Performs the conversion manually without relying on Python's built-in hex() function.

## Example

Input:

`rgb_to_hex(r=119, g=119, b=199)`

Expected output:

`#7777C7`
